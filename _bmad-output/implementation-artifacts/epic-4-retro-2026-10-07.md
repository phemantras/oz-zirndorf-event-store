Das folgt aus den ACs von 4.1 (Log-Level und Antwort bei Deadline) und ist keine Verletzung. → accept.

**Duplication map.**
- **D-1 Deadline-Klassifizierung zweimal, mit abweichendem Verhalten.** `publicapi/v1/problem.go:104-115` (`answerFailedRequest`) unterscheidet `DeadlineExceeded` → Warn/503, `Canceled` → Info/500, sonst Error/500. `admin/handler.go:315-321` (`logRequestFailure`) unterscheidet nur `DeadlineExceeded` → Warn, sonst Error. Ein vom Client abgebrochener Admin-Request wird deshalb als Error geloggt, in der öffentlichen API als Info (dort seit B1). Quelle: Diff, Linsen adversarial #5 und edge-case #2, am Code bestätigt. → **fix now** (D1).

**God-class / Größenwachstum.** Größtes Volumen: `admin/handler_test.go` +337 netto (jetzt 891 Zeilen), `publicapi/v1/gzip_test.go` +264, `cmd/eventstore/deadline_test.go` +232.
